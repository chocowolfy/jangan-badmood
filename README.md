# Jangan badmood lagi ya 🌸

Website kecil berisi animasi bunga dengan pesan "jangan badmood lagi ya".

- `index.html` : halaman pembuka (tombol **Open**)
- `flower.html` : halaman bunga + teks yang muncul huruf demi huruf
- Ubah teks pesan di `js/main.js` (baris `const titles = '...'`)

Dibuat dengan HTML, CSS, dan JavaScript biasa (tanpa build).
